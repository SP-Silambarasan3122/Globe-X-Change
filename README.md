# GlobeXchange – Currency Converter

A simple offline currency converter built using HTML, CSS, JavaScript, and Java.

## Features
- Converts between 10 currencies.
- Currency swap and dark mode.
- Conversion history.
- Works offline.

## Technologies
HTML, CSS, JavaScript, and Core Java.

## How to Run
1. Open `index.html` in a browser.
2. Enter an amount and select currencies.
3. Click **Convert**.

To run the Java logger:

```bash
javac CurrencyLogger.java
java CurrencyLogger
```

**Note:** Exchange rates are predefined and not live rates.
